Развёрнуто на GitHub Pages

Демо-сайт

Статическая страница, опубликованная бесплатно через GitHub Pages. Пример для презентации по теме «Бесплатные облачные решения».

Сайт работает по HTTPS

Что показывает это демо

Хостинг статики

HTML, CSS и JS раздаются с CDN GitHub без своего сервера.

Бесплатный HTTPS

Сертификат выпускается автоматически для домена *.github.io.

Деплой из Git

Каждый git push в ветку обновляет сайт.

Исходный код: github.com/senLoveY/github-pages-demo
